# 作品范围与验收基线

**确认时间：** 2026-08-07  
**蒸馏项目：** news-queen-vGPT-DS  
**来源：** request ticket 01

## 作品范围

- 覆盖《新闻女王》第一部与第二部
- 采用整体作品视角，提炼新闻行业、职场竞争、组织权力和职业选择的思维框架
- 重点提炼可迁移到现实新闻、职场和组织问题的分析方法
- 不模拟单一角色，不使用角色扮演
- 不将作品分析等同于编剧立场、演员观点或剧中人物真实观点

## 蒸馏定位

- 类型：主题型 Skill（topic-framework）
- 定位：全面画像 + 思维顾问
- 用途：为新闻、职场、组织和竞争问题提供类似剧中人物的分析框架
- 输出名称：news-queen-vGPT-DS

## 蒸馏配置

- 档位：深度（6 维度完整调研，多 Agent 并行，双 Agent 精炼）
- 语料模式：纯网络搜索（无本地素材）
- 来源规则：排除知乎、微信公众号、百度百科；优先权威媒体、播客、官方资料

## 事实与推断区分规则

| 层级 | 定义 | Skill 使用方式 |
|------|------|---------------|
| 剧中明确表达 | 角色在剧中说出的观点、做出的行为、事件结果 | 可直接引用为作品事实 |
| 行为证据 | 角色多次出现一致行为，间接反映价值观或判断模式 | 可作为分析依据，标注推断程度 |
| 分析推断 | 基于多个行为证据和上下文归纳的模式 | 需明确标注为推断 |
| 外部评价 | 媒体、评论者对该作品的评价和分析 | 标注来源，不作为作品事实 |
| 推测 | 从作品框架延伸到现实问题的判断 | 使用条件式语言，标注基于框架 |

## 验收标准

- [ ] 覆盖第一部和第二部
- [ ] 采用整体作品视角，而非单一角色模仿
- [ ] 明确区分剧中事实、创作者表达、外部评论和模型推断
- [ ] 可用于分析现实新闻、职场和组织问题
- [ ] 不将 Skill 宣称为编剧、演员或剧中人物的真实观点
- [ ] 对作品未明确讨论的问题保持诚实边界
